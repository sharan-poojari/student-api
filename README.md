# Student API

A RESTful API built using **Node.js**, **Express.js**, **MongoDB**, and **Mongoose** following the **MVC Architecture**.

## 🚀 Features

- Create Student
- Get All Students
- Update Student
- Delete Student

## 🛠️ Technologies Used

- Node.js
- Express.js
- MongoDB
- Mongoose
- Git
- GitHub

## 📁 Project Structure

```text
student-api
│
├── controllers
├── models
├── routes
├── server.js
├── package.json
└── .gitignore
```

## ⚙️ Installation

Clone the repository:

```bash
git clone <repository-url>
```

Install dependencies:

```bash
npm install
```

Run the server:

```bash
node server.js
```
